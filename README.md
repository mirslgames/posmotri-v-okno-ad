# «Посмотри в окно» — проектная работа

https://github.com/mirslgames/posmotri-v-okno-ad

Репозиторий: `posmotri-v-okno-ad`

## Состав проекта

- `index.html` — исходная HTML-разметка и шаблоны динамических элементов;
- `styles/style.css` — стили страницы, формы, карточек и интерактивных состояний;
- `styles/preloader.css` и `styles/error.css` — исходные стили загрузки и ошибок;
- `fonts/` — локальные шрифты;
- `scripts/script.js` — исходная логика загрузки, поиска и переключения видео;
- `.github/workflows/tests.yml` — автоматическая проверка после публикации коммитов.

При выполнении работы изменён только файл `styles/style.css`; исходная HTML-разметка, JavaScript и технические стили прелоадера/ошибок сохранены.

## Локальный запуск

Откройте `index.html` в браузере или запустите локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Для загрузки видео нужен интернет: приложение получает данные с внешнего API Практикума.

## Отправка в GitHub

Если стартовый репозиторий уже находится в вашем аккаунте GitHub, сохраните его историю и замените в нём файл `styles/style.css` на готовый из этого архива, затем сделайте commit и push. Действующий workflow `.github/workflows/tests.yml` запускается при push.

```bash
git add styles/style.css
git commit -m "Style Posmotri v okno project"
git push origin main
```

**Примечание:** для визуального соответствия макету проверьте страницу в браузере и результаты CI-тестов в разделе `Actions`.
